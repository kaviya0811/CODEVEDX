# UI Evidence

These screenshots were captured from the current managed Preview without changing the existing design:

- `dashboard.webp` — Dashboard with summary cards, circulation and recent activity.
- `add-book.webp` — Add a new book form.
- `issue-book.webp` — Issue a book form with availability-aware selector.
- `return-book.webp` — Active loans and return actions.
- `available-books.webp` — Searchable available-books view with stock indicators.

The app is a client-side single-page interface, so these views share the same root URL and are reached through the sidebar navigation.
